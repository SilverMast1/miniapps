## 🔒 Arquitectura de Ciberseguridad y Privacidad

1. **Client-Side First:** Toda la lógica de conversión (Excel a PDF, Word a HTML, compresión de imágenes, renderizado de video PiP y análisis de contraseñas) corre directamente en el motor JavaScript / WebAssembly del navegador. Ningún documento personal, contraseña o video sale de la máquina del usuario.
2. **Subresource Integrity (SRI):** Todas las librerías CDN importadas (`xlsx`, `mammoth`, `jspdf`, `jsbarcode`, `diff`, `pdf-lib`, `lamejs`, `imagetracerjs`, `qrcodejs`) están verificadas con hashes criptográficos `sha384` estrictos.
3. **Content Security Policy (CSP):** Encabezados y metas CSP configurados para impedir ataques de Cross-Site Scripting (XSS) e inyección externa.
4. **Cero Secretos / Cero APIs de Pago:** No se requieren tokens privados, claves secretas ni suscripciones.
