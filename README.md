## 🔒 Medidas de Ciberseguridad y Privacidad Implementadas

1. **Procesamiento 100% Local en tu Navegador:** Tus fotos, videos, grabaciones, documentos PDF y contraseñas se procesan de forma privada en tu propio equipo.
2. **Subresource Integrity (SRI):** Todas las librerías externas cuentan con hashes criptográficos `sha384` para evitar inyecciones de código.
3. **Content Security Policy (CSP) Estricta:** Bloqueo de orígenes no autorizados y navegación segura con `referrer="no-referrer"`.
