## 🔒 Medidas de Ciberseguridad y Privacidad Implementadas

1. **Procesamiento 100% Local en tu Navegador:** Tus fotos, documentos PDF, videos locales y hojas de datos se convierten directamente en la memoria de tu navegador mediante APIs nativas (`Canvas`, `Web Audio API`, `FileReader`) sin subirse a servidores de terceros.
2. **Eliminación Automática de Metadatos EXIF:** El convertidor de imágenes limpia automáticamente las etiquetas EXIF (como coordenadas GPS o modelo de cámara) al exportar.
3. **Subresource Integrity (SRI):** Todas las librerías externas (`qrcode.js`, `jsPDF`, `pdf.js`, `lamejs`) cuentan con verificación criptográfica `sha384` para impedir manipulaciones de CDN.
4. **Content Security Policy (CSP) Estricta:** Cada herramienta restringe exactamente los orígenes permitidos y protege tu navegación con `referrer="no-referrer"`.
